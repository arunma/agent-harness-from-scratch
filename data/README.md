# data/

- `bank.db` (git-ignored) — synthetic bank from `scripts/seed_bank.py`. Fake, deterministic, safe to reset.
- `corpus/` (git-ignored) — public MAS notices and guidelines you download for Days 6–7 (PDF). Start from https://www.mas.gov.sg/regulation
- `golden/` — your hand-labelled golden set (Day 6), committed to git: questions with the correct chunk IDs. Hand-labelling is the point; don't generate it.

Never put real customer data anywhere in this repo.
