# adapters/ — learn zone

Thin wrappers that put adopted tools behind *your* interfaces, so every comparison runs on the same eval.
Examples: `d10_mem0_store.py`, `d10_graphiti_store.py`, `d03_nemo_rails.py`, `d13_litellm_client.py`, `d12_claude_agent_sdk_port.py`.
Keep each adapter small; record the five-question tool verdict in the journal after each one.
