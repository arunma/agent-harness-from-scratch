# Journal — Claude drafts, you finish

One file per day: `day-01.md`, `day-02.md`, … At the end of each day, run `/journal` — Claude reads the day's `git diff` and the session's conversation and drafts the file from `TEMPLATE.md`, marked at the top as a draft.

Review and revise every section yourself, in your own words. Nothing from the sprint counts as done until you've done that — a draft Claude wrote is not a finished entry.
